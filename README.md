# Test Cypress Heroes

## :brazil: Português
Este é um projeto de estudo de automação de testes, usando a ferramenta Cypress e Javascript. Este conteúdo foi desenvolvido baseado no conteúdo de aula da *LumeStack* - Guardião da Qualidade.
Para a execução deste cenário, é necessário primeiramente a instalação do Cypress Heroes. Ela simila um jogo de cartas e está disponível em: [cypress-heroes](https://github.com/cypress-io/cypress-heroes). Durante o processo de instalação, passei por alguns problemas que foram descritos no arquivo "historico_testes_cypress_heroes". 

## Instalação
Após baixar e descompactar o conteúdo, executar em um prompt de comando - recomendo o uso do **bash** - dentro do diretório contendo os arquivos
```bash
npm install
```
>**Nota:**
>
>É necessário ter o **node JS** instalado.

## Executando
```bash
# Usando a User Interface (UI) do Cypress
npx cypress open

# Usando somente a linha de comando
npx cypress run
```

## :🇺🇸: English
This is a test automation study project using Cypress and JavaScript. The content was developed based on classes from *LumeStack* - Guardião da Qualidade.

For the execution of this scenario, it is first necessary to install the Cypress Heroes. It simulates a card game and it is available in: [cypress-heroes](https://github.com/cypress-io/cypress-heroes). During the installation process, I encountered some issues that were described in the file "historico_testes_cypress_heroes".

## Installation
After downloading and extracting the content, run the following command in a terminal — I recommend using **bash** — inside the project directory:
```bash
npm install
```
>**Note:** 
>
>**Node.js** must be installed.

## Running
```bash
# Using Cypress User Interface (UI)
npx cypress open

# Using command line only (Headless mode)
npx cypress run
```
